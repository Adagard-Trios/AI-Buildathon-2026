# What it looks like

"Only 10 slots left", "your friend already joined", a timer on the payment page.

# How it is used

Urgency is read as a red flag but no rule fires on it alone: honest offers can have deadlines
too. It strengthens the combined risk score (S6, S7) alongside other flags.
